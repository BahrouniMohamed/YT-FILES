# الروتين

كلها يدوية الحين. ما تتجدول ولا تشتغل تلقائيًا إلا بعد موافقة المالك على كل مهمة مجدولة.
الأوقات مقترحة ويعدّلها المالك، بنظام 12 ساعة.

## توزيع ساعتَي المالك اليومية (مقترح)
| الفقرة | المدة |
|---|---|
| ملخص الصباح | 10 دقائق |
| مراجعة وموافقات خلال اليوم | 90 دقيقة |
| ختام اليوم | 15 دقيقة |
| احتياط للطارئ | 5 دقائق |

## 1. ملخص الصباح
- الوقت المقترح: 8:30 ص
- من: المدير التنفيذي
- المحتوى: «ينتظرك» أولًا مرتبًا بالأولوية، ثم اللي تم أمس، ثم خطة اليوم لكل قسم (ومين يحتاج المالك يفتح جلسته)، ثم المتوقف.
- المخرج: work/ceo/briefs/التاريخ-morning.md بصيغة README

## 2. ختام اليوم
- الوقت المقترح: 6:00 م
- من: المدير التنفيذي
- المحتوى: جمع تقارير الأقسام، دفع outbox للوحة، تسجيل XP للمقبول فقط، تحديد قرارات الغد.
- المخرج: work/ceo/briefs/التاريخ-closing.md

## 3. اجتماع الأسبوع
- الوقت المقترح: يوم يحدده المالك، 7:00 م، 30 دقيقة
- المحتوى: أرقام الأسبوع من التحليلات، المنجز مقابل المخطط، المتوقف، قرارات المالك، خطة الأسبوع القادم، الـXP والمستويات.
- المخرج: work/ceo/briefs/الأسبوع-weekly.md

## 4. المراجعة الشهرية
- الوقت المقترح: أول أسبوع من الشهر، 60 دقيقة
- المحتوى: مراجعة كل قسم، الترقيات والنزول، مخالفات الشهر، تعديلات مقترحة على jd وchecklists وlevels (المالك يوافق قبل أي تعديل)، تقييم المجال والخطة، الأدوات المقترحة وملفاتها للعرض على المالك.
- المخرج: work/ceo/briefs/الشهر-monthly.md

## 5. فحص الليل
- الوقت المقترح: 11:30 م
- من: المدير التنفيذي (بدون المالك)
- المحتوى: مهام عالقة أكثر من 24 ساعة، تعارض بين اللوحة والملفات، أسرار أو كلمات سر في الملفات، مصادر أو تراخيص ناقصة، مخالفات للقواعد، وتجهيز مسودة ملخص الصباح.
- الحدود: فحص وتقرير فقط، ما يغيّر شي خارج المجلد ولا يرسل ولا ينشر.
- المخرج: work/ceo/briefs/التاريخ-nightcheck.md
